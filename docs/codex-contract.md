# Codex native contract

Racco supports **`@openai/codex@0.160.0` on Linux**. Install that exact version with `npm install -g @openai/codex@0.160.0`. The app-server handshake must report that version and the Linux platform before Racco sends session RPCs. Updating the supported release requires a new no-model smoke run and review of the affected generated schema.

The driver selects the current release's experimental `historyMode: "legacy"` full-history storage for new threads. This is the one Racco history contract, not a fallback to another Racco version. Codex 0.160.0 defaults to `paginated`, whose `thread/read` with `includeTurns: true` currently returns `-32601: list_turns is not supported yet`. Racco cannot import that native history mode; it reports the native error rather than silently showing an empty conversation. Empty, unmaterialized native threads also reject `includeTurns` until their first input; Racco's allocated-session handling owns that distinction.

Run `node --import tsx scripts/smoke-codex-contract.mjs` to verify the installed binary. `RACCO_CODEX_BIN=/absolute/path/to/codex` selects an explicit executable. The smoke uses a temporary `HOME` and `CODEX_HOME` without inherited credentials, starts one full-history thread, executes only the fixed `printf racco-contract-smoke` shell command, reads its real history, and removes its state after the native process exits. It sends no model request and does not access the daemon.

`test/fixtures/codex/0.160.0-shell-transcript.json` is a captured CLI exchange from that no-model workflow plus read-only loaded-thread checks. Only temporary paths, native IDs and the rollout filename were replaced; the unrelated remote-control status notification was omitted to remove machine identity. It contains real command events, not an invented assistant conversation. Tests map its real completed-command notification and validate its history response. The shell-only turn is recorded as completed with no persisted items by this CLI; the smoke does not pretend that the shell event was persisted. Model-generated multi-agent exchanges remain covered by explicitly synthetic fixtures; this transcript does not establish end-to-end model behavior.

Upstream protocol: <https://github.com/openai/codex/blob/rust-v0.160.0/codex-rs/app-server/README.md>. The authoritative local schema is emitted by `codex app-server generate-json-schema --experimental --out DIR` for this release. In particular, `thread/unsubscribe` acknowledges removal of a subscription; our real no-model probe still observed the thread in `thread/loaded/list` afterwards, so Racco does not treat that ACK as proof of native execution ownership release.

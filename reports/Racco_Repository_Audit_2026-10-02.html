R01 · Worktree 创建失败的回滚会误删外部进程创建的数据

固定提交位置：src/server/worktrees/manager.ts:132-145

触发与影响：目标路径预检后被其他进程创建，真实 Git 正确拒绝 worktree add，但 catch 无条件递归 rm(target)。隔离实验中 important.txt 被删除。

R02 · 实例锁允许两个 daemon 同时持有同一个 state

固定提交位置：src/server/state/database.ts:60-81 · src/server/state/database.test.ts:10-19

触发与影响：排他创建锁文件到写入 JSON 之间是空文件窗口。B 把 A 的未完成锁当作无效锁删除，两进程均 DATABASE_OPEN 成功。实验在写入前暂停 1.8 秒，持有时间发生重叠。

最小建议：改用 Linux 内核独占锁；至少对未完成锁 fail closed，并解决 stale-lock 回收竞争。SQLite 写锁不能替代应用单实例锁。

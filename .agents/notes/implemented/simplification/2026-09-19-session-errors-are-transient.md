# Agent Note: 会话可用性与错误只在操作时反馈

Status: implemented

## Problem

Provider 可用性和目录存在性会随外部环境变化，持久化健康标记可能过时，并与原生会话存在状态重复。最近错误跨多种操作覆盖写入，却没有用于恢复后的界面展示。

## Decision

会话不保存或输出 health，也不保存 last_error。读取历史、发送消息和压缩继续检查当前依赖，通过请求错误或即时会话通知反馈失败。首次创建失败返回具体原因；重复提交同一失败创建请求只返回通用创建失败提示。其余会话字段与创建幂等、执行中断恢复语义保留，全局 Provider 状态接口继续服务创建界面。

本决策进一步限定[无逐轮执行记录](2026-09-17-session-state-without-turn-ledger.md)的会话持久化边界；该记录继续持有逐轮存储与重放的取舍，没有被替代。原生历史仍归 Provider 所有。

## Alternatives considered

**保留健康状态并主动刷新：** 增加同步写入和失效规则，实际操作仍然必须检查依赖。

**保留最近错误用于恢复展示：** 当前只需要即时错误提示，不承担跨重启保存诊断信息的功能。

## Consequences

会话错误详情不承诺跨刷新或 daemon 重启保留；当前操作仍提供具体错误，执行失败和中断状态继续持久化。压缩不再依赖缓存健康标记禁用按钮，服务端实际检查仍然拒绝不可执行的操作。旧数据库版本直接拒绝，不提供迁移；仅在出现明确的历史诊断需求时重新评估错误持久化。

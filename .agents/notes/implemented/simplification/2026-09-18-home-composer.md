# Agent Note: 首页直接输入任务并统一发送快捷键

Status: implemented

## Problem

首页要求用户先进入新建对话才能输入任务，增加了没有提供额外选择的一步；新建输入框和已有对话对 Enter 的处理不同，导致同一发送习惯在两处产生不同结果。

## Decision

未打开已有对话时直接显示带 Racco 标志的新建输入页，移除独立欢迎页及其入口按钮。两处输入框共用键盘处理：Enter 提交，Shift + Enter 换行，输入法组词时保留 Enter 的默认处理；提交继续经过各自表单的项目、连接和模型配置校验。窄屏默认进入输入页，历史列表通过返回入口访问。输入页与列表共用 URL，但各自视图随浏览器历史记录保存，前进后退与刷新能恢复列表；重新激活输入页时显式恢复焦点，避免依赖重新挂载组件而丢弃草稿。

同范围审查保留[模型选择](../feature/2026-09-17-composer-model-selector.md)的配置与提交约束；[产品标识](../feature/2026-09-18-racco-product-identity.md)只更新首页展示位置，品牌决策继续有效。没有记录被完整替代。

## Alternatives considered

**保留欢迎页，只删除说明文字：** 用户仍需多次操作才能开始输入，不能消除入口冗余。

**两处分别实现快捷键：** 修复当下行为后仍容易再次分叉；共用处理保证相同的发送与输入法边界，同时保留不同的表单职责。

## Consequences

首页可直接开始任务，切换到已有对话后无需改变输入习惯；多行任务统一需要 Shift + Enter。首页会随项目与连接状态加载模型目录，但只有有效提交才创建会话。桌面保留侧栏入口，窄屏需显式返回才能查看历史；浏览器前进后退必须继续正确恢复输入页、历史列表或已有对话。在输入页与列表之间切换时保留草稿和输入能力，不扩展为跨刷新保存草稿。

# Agent Note: 工具名称保持记录原名

Status: implemented

## Problem

把工具名翻译或替换成动作类别，会让同一调用在 Chat、详情和原生工具文档中出现不同名字，也可能把通用命令误认成独立的文件工具。

## Decision

所有工具展示入口使用记录中的工具名，保留大小写和命名空间。命令动作分类只提供摘要，不再替换名称；Codex 只给出通用调用标识时使用该标识，不猜测底层工具名。操作对象、结果和进度仍由已有事实生成。

本决策部分替代[工具活动摘要](../feature/2026-09-22-tool-activity-summaries.md)的名称翻译及动作类别命名，摘要可见性、紧凑布局与按需详情继续有效。折叠计数按工具原名归组，不按命令的推断用途归组。

## Alternatives considered

**继续翻译，或只对部分工具保留原名：** 能解释部分工具的用途，但识别规则不一致；工具原名负责身份，摘要负责用途，两者无需互相替代。

## Consequences

卡片、折叠摘要、子对话和详情名称一致，用户可直接对照工具文档。通用协议标识可能不如动作名直观，因此保留命令动作、路径及查询摘要；长名称仍受紧凑布局限制，完整名称可在详情查看。

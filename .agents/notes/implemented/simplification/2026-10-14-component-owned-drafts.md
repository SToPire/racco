# Agent Note: 未发送草稿随输入组件生命周期保留

Status: implemented

## Problem

未发送文字与图片存于输入组件，首页进入已有会话或会话视图被缓存淘汰时会丢失草稿。扩大保存范围可以减少重复输入，但需要独立的草稿所有权、订阅、图片读取和资源清理机制，成本超过当前需求。

## Decision

保留组件持有草稿的现状，不引入页面级草稿仓库或浏览器、服务端持久化。已有会话的草稿随最近访问视图缓存保留，视图淘汰后允许丢失；首页进入已有会话会卸载输入区，返回首页不恢复原草稿。首页切换项目或工作目录时保留文字并清空图片，不保存各目录的图片草稿。刷新、关闭页面、删除所属会话或项目也不承诺恢复未发送输入。这些边界内的草稿丢失是接受的产品取舍，不应仅据此报告为缺陷或引入独立保存机制。

仍保持已承诺的组件内行为：Chat 与 Trajectory 切换、首页输入页与历史列表切换，以及尚未淘汰的会话视图切换保留草稿；组件仍挂载时，发送失败或连接断开不主动清空草稿，发送确认前锁定编辑，成功确认后清空。图片读取的过期结果不得写入其他目录或卸载后的草稿，离开图片作用域时释放本地预览。跨会话串入图片、错误清空仍有效的草稿、重复发送或损坏已受理输入仍属于缺陷，不能以本决策豁免。

本记录明确[会话视图缓存](../bug-fix/2026-09-22-session-switching.md)与[首页输入页](2026-09-18-home-composer.md)的草稿保存范围，不替代其导航和阅读位置决策。[跨视图控制](../feature/2026-09-22-continuous-session-controls.md)的持续挂载与未确认发送锁定、[无逐轮记录](2026-09-17-session-state-without-turn-ledger.md)的不自动重发，以及[临时聊天图片](../feature/2026-09-27-ephemeral-chat-images.md)的本轮输入完整性继续有效；没有需要完整替代或归档的记录。

## Alternatives considered

**独立页面级草稿仓库：** 可以在视图卸载后恢复文字和图片，但增加作用域索引、订阅和异步读取所有权，并使图片内存不再随有界视图缓存释放。当前接受重新输入，不承担这些复杂度。

**扩大视图缓存或持久化草稿：** 扩大缓存只延后丢失并增加历史 DOM 内存；持久化增加敏感图片留存、存储和清理契约。两者均超出当前保存范围。

## Consequences

导航可能无提示地丢弃未发送工作，缓存内切换与淘汰后的恢复表现也不同；接受这一体验成本以保持状态所有权简单、图片随组件释放。草稿恢复不作为历史恢复或重连协议的一部分。只有产品明确要求跨卸载恢复时才重新评估独立保存方案；验证现有行为仍需区分被接受的生命周期丢弃与组件内保留、发送确认及图片隔离的回归。

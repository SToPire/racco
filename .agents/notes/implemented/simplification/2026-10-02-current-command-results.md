# Agent Note: 直接消费当前命令结果

Status: implemented

## Problem

创建会话的 ACK 已包含会话标识，但浏览器请求 API 丢弃结果，调用者另装消息监听器取回它；服务端也构造未被使用的创建快照。无调用方的工作树展示参数和转发方法增加了不必要的接口维度。

## Decision

WebSocket 请求直接返回对应 ACK 的结果，调用者在自己的契约边界验证并消费；创建会话仅返回引用，完整内容沿既有订阅路径取得。移除当前没有调用者的转发方法、文本输入构造函数和替代显示路径参数，不保留旧接口分支。

这是当前调用链的简化，[完整历史与压缩](2026-09-27-full-history-with-websocket-compression.md)继续持有快照语义，[Worktree 管理](../architecture/2026-09-20-git-worktree-management.md)继续持有路径身份；同范围没有被完整替代的记录。

## Alternatives considered

**保留临时监听和未用参数供以后扩展：** 当前没有第二个使用场景，却要求调用者理解消息广播顺序；未来确有需求时再增加明确契约。

## Consequences

请求失败、断线未知结果与不自动重放的行为不变。ACK 与会话快照各有一条明确的消费路径，移除的方法不再作为现行可用接口。

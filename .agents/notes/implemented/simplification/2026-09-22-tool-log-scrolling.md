# Agent Note: 工具日志使用普通滚动阅读

Status: implemented

## Problem

工具详情主要用于检查一次调用的证据，额外的跟随开关要求用户理解和维护另一种阅读状态，增加界面负担。

## Decision

工具日志使用浏览器普通滚动，删除跟随按钮、自动滚动逻辑及相关状态和样式。输出继续更新并可复制，新增内容不会由应用主动滚至末尾。这一决定部分替代[工具详情阅读体验](../feature/2026-09-22-tool-inspector-results.md)的日志跟随机制；结果优先、选项卡选择和主对话的阅读位置规则继续有效。

## Alternatives considered

**保留或隐藏跟随开关：** 原本用于兼顾实时观察和回看，但详情中的手动阅读已满足当前需求；隐藏入口仍留下不可见的模式切换，不能消除复杂度。

## Consequences

详情少一个操作和状态，代价是查看最新日志需要手动滚动。若未来有明确的持续监控场景，再评估自动跟随；主对话已有的追踪进展能力不因此改变。

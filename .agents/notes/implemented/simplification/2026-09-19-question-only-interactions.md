# Agent Note: 全权限执行只保留用户问答

Status: implemented

## Problem

Provider 已固定使用全权限模式，共享协议、Codex 驱动和界面却仍保留工具审批分支，测试也以审批模拟交互。这让已取消的权限选择继续成为可执行的产品契约。

## Decision

工具执行由 Provider 的全权限配置决定，Racco 的交互请求只承载问题与回答。移除工具审批请求类型、允许响应、界面按钮和审批测试夹具；取消回答仍可返回拒绝结果。Codex 收到不支持的服务端请求时直接报错，不重新建立审批入口。

普通对话直接管理自己的启动、完成与中断，不保留只有单一调用者的通用操作执行器；压缩继续使用独立的原生操作路径。相关处理保留通知早于 RPC 响应的顺序保障。两家 Provider 都提供会话更新通知，驱动接口要求实现该回调注册方法，不再静默跳过缺失实现。

本决策补全[Claude 全权限回调](../bug-fix/2026-09-19-claude-tool-permissions.md)的共享协议与 Codex 边界，并落实[无逐轮执行记录](2026-09-17-session-state-without-turn-ledger.md)的执行路径简化。两条记录继续持有各自的回调和持久化取舍，没有被完整替代。

## Alternatives considered

**保留审批作为备用入口：** 会让固定的全权限模式重新出现第二套权限行为，并要求维护不再使用的协议与界面。

**一并移除问答和中断处理：** 会损失当前任务所需的用户输入与取消能力；这些能力不属于版本兼容或工具审批。

## Consequences

用户仍能回答问题、打断等待中的任务，并在重连后看到待回答的问题。客户端只能提交当前问答响应；旧审批消息不会被解释或转换。状态库版本拒绝、当前会话恢复、Provider 历史投影和流式重试处理继续保留。

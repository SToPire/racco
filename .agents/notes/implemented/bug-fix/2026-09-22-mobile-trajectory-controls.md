# Agent Note: 窄屏轨迹详情保留会话操作区

Status: implemented

## Problem

窄屏轨迹详情使用覆盖布局，却以整个会话作为定位容器，打开详情会遮住问题、停止入口及视图导航，使跨视图可操作性在手机上失效。

## Decision

轨迹内容区使用会话剩余高度并独立滚动，桌面工作区中的局部详情保留并排操作能力。[覆盖式面板的模态焦点](2026-10-02-responsive-panel-focus.md)部分替代本记录的手机背景交互选择：手机覆盖式详情使用全屏模态，必须关闭后才能回答问题或停止任务；草稿和未提交回答继续由[连续会话操作](../feature/2026-09-22-continuous-session-controls.md)保留。

## Alternatives considered

**所有宽度都要求先关闭详情：** 增加桌面并排工作的操作负担，因此只在覆盖式手机布局接受这项成本，以满足可靠的焦点与背景交互边界。

## Consequences

桌面窄工作区保留局部详情和会话控制，长内容在详情内部滚动。手机以关闭详情后返回原操作点换取明确的模态边界，问答与草稿不因关闭而清空。

# Agent Note: 窄屏轨迹详情保留会话操作区

Status: implemented

## Problem

窄屏轨迹详情使用覆盖布局，却以整个会话作为定位容器，打开详情会遮住问题、停止入口及视图导航，使跨视图可操作性在手机上失效。

## Decision

轨迹详情仅覆盖轨迹内容区，搜索工具栏和会话操作区保持可达；内容区使用会话剩余高度并独立滚动。本修复落实[连续会话操作](../feature/2026-09-22-continuous-session-controls.md)在窄屏上的同一决定，没有替代其他展示或交互记录。

## Alternatives considered

**要求用户先关闭详情再操作任务：** 能维持原覆盖布局，却增加响应问题或停止任务的操作负担；详情不需要占用会话控制区。

## Consequences

手机和窄工作区可以在查看轨迹详情时回答问题或停止任务，代价是详情可用高度较少；长内容在详情内部滚动。

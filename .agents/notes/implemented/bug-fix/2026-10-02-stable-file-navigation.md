# Agent Note: 文件导航上下文按会话稳定

Status: implemented

## Problem

根组件的每次流式更新都会创建新的文件导航值，穿透 memo 触发隐藏会话的 Markdown 重新解析；隐藏会话还共享当前活动会话的工作目录。

## Decision

每个保留的会话视图持有稳定的文件导航上下文，其根目录固定于该会话，打开文件的回调显式携带目录；子 Agent 的相对目录覆盖只在目录或父上下文变化时更新。顶层工具详情继续使用活动会话的上下文。此决策补充[文件引用](../feature/2026-09-22-project-file-references.md)和[会话视图缓存](2026-09-22-session-switching.md)，保留其目录边界、缓存上限和完整历史选择，没有完整替代的记录。

## Alternatives considered

**移除隐藏会话或直接引入历史虚拟化：** 会牺牲阅读状态，且不能修复上下文不断变化的根因。仅 memo Markdown 组件也无法阻止 context 变更，因此先稳定真正影响解析的输入。

## Consequences

无关会话的流式更新不会重新解析已缓存 Markdown，文件引用仍打开内容所属的 Worktree。性能验证以长历史缓存与实际流式更新中的渲染次数为依据；未因此拆分渲染框架、增加消息索引或改变首载资源边界。

# Agent Note: 选项与其他回答保持同一提交语义

Status: implemented

## Problem

问答使用同一个数组接收选项与自由文字，多选后的文字编辑会覆盖勾选内容。单选改回选项时，未受控文本框仍显示旧文字，导致界面表达和实际提交不一致。

## Decision

选项和其他文字分别受控，在提交时组成现有回答数组。多选允许勾选项与非空其他文字并存；单选在选项与文字之间互斥，切换时同步清空另一个输入。空的其他文字不额外产生回答，未触碰问题维持未回答语义。

本修复落实[仅用户问答](../simplification/2026-09-19-question-only-interactions.md)的输入完整性，保留[连续会话控制](../feature/2026-09-22-continuous-session-controls.md)的跨视图回答保留。协议与 Provider 转换不变，没有需要替代或归档的现有记录。

## Alternatives considered

**让其他文字始终替代选项：** 适用于单选，但会抹掉多选题仍有效的勾选结果。

**为其他文字新增协议字段：** 可以显式区分答案来源，但现有 Provider 接受回答数组，问题发生在本地编辑状态，无需扩展共享契约。

## Consequences

用户看到的选中项和其他文字与提交值一致，多选中继续修改文字不会取消有效选项。浏览器回归覆盖两种编辑顺序、单选互斥、跨视图保留及实际发送的答案，避免只根据初始静态表单判断正确性。

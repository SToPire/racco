# Agent Note: 会话完成后更新 Provider 标题

Status: implemented

## Problem

新会话的标题可能在首轮执行后才由 Provider 生成，仅在打开会话时读取元数据会让侧栏继续显示占位标题，用户需要重新打开会话才能看到名称。

## Decision

驱动在成功执行后异步读取该会话的 Provider 元数据，通过共享更新通道交给会话管理层保存；标题变化时广播给连接的客户端。刷新失败不改变本轮执行结果，后续读取快照仍可取得最新元数据；相同标题不重复广播。

本决策补充[会话状态简化](../simplification/2026-09-17-session-state-without-turn-ledger.md)的会话级元数据同步，不新增逐轮持久化；也不改变[项目会话导入](../feature/2026-09-18-project-session-import.md)的按需发现范围。两项记录继续有效。

## Alternatives considered

**继续只在打开时刷新：** 不增加 Provider 请求，但无法及时展示生成后的标题。

**阻塞本轮完成直到刷新成功：** 能使完成与标题同步到达，却将非关键元数据读取失败变为执行失败；异步刷新保留执行结果的独立性。

## Consequences

已有连接可以收到更新后的会话标题，无需重新打开对话。每次成功执行增加一次定向元数据读取，标题更新允许短暂延迟或在刷新失败时等待下次快照；Provider 仍是标题的来源。

# Agent Note: 文件预览按行数限制渲染预算

Status: implemented

## Problem

文件字节上限不能限制行号节点数量；大量短行可在允许的文件大小内生成庞大的 DOM，影响整个工作区交互。

## Decision

只读文本预览按固定行数分页，保留总行数与当前位置，行号引用自动进入目标页。文件读取与全文复制仍遵守现有字节和总行数上限；正文只拆行一次，分页文件不做全文高亮。此决策补充[文件引用](../feature/2026-09-22-project-file-references.md)，不改变 Worktree 读取边界和缺失行反馈；同范围没有完整替代的记录。

## Alternatives considered

**仅降低字节上限：** 不能可靠约束换行密度，还会拒绝行数合理的文件。引入虚拟编辑器则增加滚动与定位复杂度，分页足以支持当前只读浏览。

## Consequences

大量短行的渲染节点受每页预算约束，用户可以继续翻页和切换其他文件。长文件放弃连续滚动与语法高亮，换取可预测的交互成本；分页不会改变全文复制内容。

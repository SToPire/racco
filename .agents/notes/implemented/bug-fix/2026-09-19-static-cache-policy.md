# Agent Note: 静态入口重新验证与资源长期缓存

Status: implemented

## Problem

部署新前端后，浏览器复用旧入口页面会继续引用旧资源，用户可能无法在重新访问时取得当前界面。

## Decision

静态入口 HTML 每次使用前必须重新验证，其余静态资源采用长期不可变缓存。该选择依赖构建资源以内容哈希命名：资源内容变化必须生成新 URL，入口更新后浏览器自然获取新资源。

本决策补充[产品标识](../feature/2026-09-18-racco-product-identity.md)中资源由构建工具直接引用的约束，不替代其品牌与运行契约。现有活动记录没有独立的静态响应缓存策略需要取代。

## Alternatives considered

**所有静态文件长期缓存：** 入口 URL 固定，会延迟新版本生效。

**所有静态文件都重新验证：** 更新正确，但带哈希资源内容不变时仍需额外请求；仅入口重新验证保留资源缓存收益。

## Consequences

重新访问时入口可更新，已缓存且 URL 未变的资源可以直接复用。长期缓存要求未来新增静态资源也使用随内容变化的 URL；若引入固定 URL 的可变文件，必须同步调整缓存分类。此策略不主动刷新已经打开的页面。

# Agent Note: 不可用会话有明确退出与重试

Status: implemented

## Problem

过期会话链接和首次历史读取失败时，界面只显示旋转标记与错误文本。缺少会话实体时也缺少返回入口，手机用户会被困在永久读取画面。

## Decision

首次会话读取区分读取中、已就绪、不存在和失败。不存在由订阅协议的明确错误码表达；失败停止旋转，并提供重新订阅与返回项目入口。首次连接也有期限，网络黑洞不能让读取画面无限等待。已加载的缓存视图继续可读，刷新失败不会销毁对话。

本记录补充[会话切换](2026-09-22-session-switching.md)的导航失败分支和[WebSocket 活性](2026-10-02-websocket-liveness.md)的连接建立期限；二者其余决策继续有效，没有完整替代的记录。

## Alternatives considered

**依据英文错误文本识别不存在：** 文案变化会改变导航行为，协议错误码使用户提示与状态语义独立。

**错误后自动退回列表：** 用户会失去失败原因和重试机会，明确入口也保留了手机用户的操作选择。

## Consequences

重试仅重新读取会话，不重发任务；返回入口不依赖会话、Worktree 或侧栏是否存在。缓存内容与最新连接状态分别展示，错误不会把可读历史清空。

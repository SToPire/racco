# Agent Note: Claude 工具结果保留结构化事实

Status: implemented

## Problem

Claude 同时提供面向模型的工具结果文本和完整结构化结果。只保留前者会丢失实际修改差异、stderr、后台任务及输出附件信息；SDK 的公开历史消息投影还会去掉原生记录中的结构化结果，导致刷新前后的详情不一致。

## Decision

[结果映射](../../../../src/server/drivers/claude/event-mapper.ts)将原生结构化结果与模型收到的内容共同保留在工具完成事件的详情中。原生中断标记形成中断终态，不由任意输出文本推断。历史继续由 SDK 选择会话分支和压缩后的消息，再按消息 UUID 从当前原生记录恢复其结构化结果；没有记录的字段保持缺失，不解析文本补造数据。

[活动摘要](../../../../src/web/claude-tool-result.ts)消费已验证的差异和后台任务身份。没有差异片段不代表文件没有变化，后台任务回执也不代表后台进程已完成。原先的结构化详情分栏由[单一输出展示](../simplification/2026-09-22-single-tool-output.md)部分替代：Output 只呈现模型收到的文本，结构化结果与非文本附件仍可在 Raw 检查，附件二进制不混入普通输出文本。

此决策扩展[工具详情阅读](../feature/2026-09-22-tool-inspector-results.md)的数据来源；[Claude 流式输出](2026-09-18-claude-streaming-output.md)继续规定事件来源和历史归属，工具结果仍来自 SDK 实际完成消息，没有新增 stdout 实时流或结果持久化层。相关记录保留，没有完整替代项。

## Alternatives considered

**从结果文本提取 diff、错误或后台状态：** 文本面向模型且可能截断，无法可靠还原结构化事实，容易将尝试、回执或 stderr 误判为完成和失败。

**仅修复实时结果或自行选择历史分支：** 前者仍在刷新时丢失信息，后者复制 SDK 的分支和压缩语义并可能恢复已丢弃内容；仅补充 SDK 已选中消息的当前原生字段。

## Consequences

工具结果需要传输更多原生数据，界面按需展开完整记录。已知结果结构缺失或不完整时仍可阅读原始输出，不承诺从缺失的历史中恢复差异或状态。SDK 原生记录字段和工具结果形状发生变化时，映射和展示必须同步更新，不能累积旧格式分支。

# Agent Note: Claude 任务进度与子对话使用原生归属

Status: implemented

## Problem

Claude 已报告工具进度、后台任务和子 Agent 的身份与结果，但这些事件未进入界面，完整子 Agent 消息还会出现在主对话中。查询结束后，缺少终态的工具和子任务可能继续显示运行中；只读取主会话也无法恢复独立子对话。

## Decision

[任务投影](../../../../src/server/drivers/claude/activity-tracker.ts)使用 SDK 原生任务身份、父工具调用和已有摘要关联进度、完整子消息与终态。原生 Agent 任务进入子对话；Bash 和其他后台任务保留通用任务身份，不因后台执行就变成 Agent。尚未关联到原生身份的子消息等待身份信息，不能混入主对话；执行流结束仍无法关联时明确提示缺失。额外的 AI 进度摘要保持关闭，也不承诺子 Agent token 流或把心跳当作 stdout。

SDK 工具进度的临时消息 ID 不代表工具调用；通过原生 `parent_tool_use_id` 关联已观测调用，并且仅在 `tool_name` 与该调用一致时沿其归属展示。子工具转发缺少内层调用身份时不猜测，也不能把子工具耗时记到委派 Agent；暂存观测同样保留来源，不与后续匹配的观测混合。进度不能新建工具，先到的观测仅暂存至原调用出现或执行流结束，未关联的进度也不构成子消息缺失。耗时保持已观测到的最大值，终态后不接受迟到进度；Agent 重试作为重试提示，控制通知里的零值不冒充执行耗时。

历史通过 SDK 的子 Agent 枚举与消息读取接口恢复，各自保留 SDK 选择的消息分支。子任务目录只来自原生 worktreePath、子任务元数据或明确记录的 cwd；缺失时不继承主会话目录。缺少工具终态时沿用完成、失败、中断与结果未知的[工具生命周期契约](2026-09-22-tool-lifecycle-states.md)。没有子任务终态的 Agent 标为状态未知并保留最近进度，普通回复文本不能证明任务已完成。

本决策补充[子任务摘要](2026-09-22-subagent-task-summaries.md)的 Provider 事实来源，并明确[Claude 流式输出](../bug-fix/2026-09-18-claude-streaming-output.md)中完整子消息的归属；原有阅读焦点与主流去重决策继续有效。[结构化工具结果](../bug-fix/2026-09-22-claude-structured-tool-results.md)继续拥有结果字段保留与可读展示，没有完整替代项。

## Alternatives considered

**把所有 SDK 消息平铺到主对话：** 容易复用现有展示，却会把并行子任务的内容当成主 Agent 回复，并失去父子任务关系。

**把后台任务统一包装成 Agent，或根据查询结束、最终回复推断完成：** 能减少状态分支，但会伪造身份或成功结果；通用任务和状态未知保留可观察事实。

**额外生成进度摘要或自行遍历原生文件推导历史：** 前者增加模型调用，后者重复 SDK 的目录、分支和压缩规则；使用现有原生事件和 SDK 读取接口即可补齐可获得的信息。

## Consequences

Claude 子任务可以独立查看进展、完整记录和已报告结果，正常轮次结束不再被误当作所有任务成功。读取子历史增加原生存储读取量，缺少身份、目录或终态的记录仍可能显示未知；界面明确表达这些缺失，不补造跨 Agent 的精确时序或历史结果。

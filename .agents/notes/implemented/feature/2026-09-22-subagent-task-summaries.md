# Agent Note: 主对话保留子任务摘要与阅读焦点

Status: implemented

## Problem

新子 Agent 开始工作时自动切换对话，会打断用户阅读主线或其他任务；主对话又缺少任务和结果摘要，用户只能逐个进入子对话了解进展。

## Decision

Chat 默认显示主 Agent，新子任务和状态更新不改变用户选择的对话或工具详情。主对话提供可进入子对话的任务卡，展示已知任务、状态和结果。摘要只引用 Provider 已报告的状态消息；没有可靠内容时明确显示缺少摘要，不从工具调用或对话文本推断结论。完整子对话和 Agent 切换器继续作为深入阅读入口。

本决策补充现有会话展示，不替代已有记录。[原生会话导入](2026-09-18-project-session-import.md)的子 Agent 归属边界和[流式输出](../bug-fix/2026-09-18-claude-streaming-output.md)的完成与中断语义继续有效；任务卡不登记独立会话，也不改变 Provider 历史。

## Alternatives considered

**继续自动切换到最新活动子 Agent：** 能立即展示活动，但把后台事件当作用户导航意图，连续产生任务时会反复打断阅读。

**仅保留 Agent 切换器：** 页面更紧凑，但用户仍需逐个打开子对话才能知道任务与结果。任务卡增加少量主线内容，使深入阅读成为显式选择。

**自动生成或推断结果摘要：** 可以得到更短的文本，却引入额外生成成本或将未完成评论误当结果；当前使用已有明确内容并允许摘要缺失。

## Consequences

用户能够持续阅读选定对话，并在主线了解子任务进展。任务卡展示摘要预览，长内容需要进入子对话；缺少任务或结果元数据时信息仍有限。这一展示投影不补造执行历史，后续扩展必须继续区分已报告结果、运行中进展和中断输出。

# Agent Note: 本地会话筛选与主流程命名

Status: implemented

## Problem

会话数量增加后，展开所有项目和 Worktree 很难快速定位目标；进行中的任务混在历史中，同类详情标签又使用不同语言和字段名称。

## Decision

历史侧栏按已加载会话标题和项目名称、路径进行本地筛选，筛选时显示命中层级，不改变原有折叠选择；进行中、等待回答和压缩中的会话集中显示，其他历史保留项目与 Worktree 分组且不重复。主流程使用“对话”“执行轨迹”，工具与轨迹详情共享“输入”“输出”“原始数据”等可读名称，保留 Provider、Worktree 和 Agent 等既有术语。此决策扩展[会话导航](../bug-fix/2026-09-22-session-switching.md)和[轨迹定位](2026-09-22-trajectory-location.md)，不改变原生历史发现与目录归属，没有完整替代的记录。

## Alternatives considered

**全站全文搜索或远端索引：** 超出当前标题定位需求，并引入历史读取、索引更新和隐私边界。仅增加排序不能帮助按项目或标题缩小范围，也无法让等待处理的任务突出。

## Consequences

用户无需展开大量历史即可查找会话和识别当前任务。筛选仅覆盖已登记的本地清单，不搜索消息正文或自动发现原生历史；切换筛选不会修改会话、原生状态或持久化数据。

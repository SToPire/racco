# Agent Note: 对话跟随与阅读位置归属

Status: implemented

## Problem

流式输出没有跟随底部的阅读策略，用户需要反复寻找新增内容。切换主 Agent、子 Agent 或轨迹后，滚动位置也不属于原先阅读的对象。

## Decision

每个会话中的主 Agent 和子 Agent 分别保存本次页面内的阅读位置与跟随状态。首次进入跟随最新内容；用户离开底部后暂停跟随，新增输出不主动改变其阅读位置，并提供明确的回到最新入口。返回同一对象时恢复其位置，内容高度变化仅在跟随状态下推动滚动。

本记录落实[可理解执行过程提案](../../proposed/feature/2026-09-22-chat-observable-work.md)的阅读连续性，与[子任务摘要](2026-09-22-subagent-task-summaries.md)保留阅读焦点的决定互补。已有会话状态、流式事件和轮次导航的归属不变，没有需要替代的滚动决策。

## Alternatives considered

**每次输出都滚到底部：** 能显示最新内容，却会打断用户回看工具错误和早先说明。

**始终保持滚动位置：** 不打断历史阅读，但使正常观察流式任务需要持续手动追踪；由用户是否贴底决定跟随更符合阅读意图。

## Consequences

跟随与回看都可持续进行，切换 Agent 或视图不会主动抹掉阅读选择。位置是当前页面的界面状态，不持久化到会话数据库，也不承诺跨刷新恢复或原生历史缺失时的精确定位。

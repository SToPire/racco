# Agent Note: 断线草稿与可确认的发送目标

Status: implemented

## Problem

已有会话断线时禁止编辑，与运行中可准备草稿的行为不一致；窄屏隐藏标题中的工作目录，用户不易确认消息的执行位置。

## Decision

连接状态只限制发送和服务端操作，断线期间允许编辑当前会话草稿，恢复连接后仍须用户显式发送。输入区保留简短 Provider 与目录名称，并可展开完整执行目录。此决策补充[持续会话控制](2026-09-22-continuous-session-controls.md)及[草稿生命周期](../bug-fix/2026-10-02-draft-lifetime.md)，保留压缩和会话不可用时的编辑限制，不扩大草稿持久化范围。

## Alternatives considered

**恢复连接后自动发送：** 容易执行过时的任务，与明确发送及无自动重放原则冲突。只在桌面标题显示目录则不能满足窄屏确认执行目标的需要。

## Consequences

用户可以在网络中断时继续准备任务，且在手机发送前确认目标；重连不会执行草稿。目录披露占用少量输入区空间，完整路径保持折叠，避免常驻长路径挤压控件。

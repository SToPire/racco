# Agent Note: 子 Agent 拓扑独立于对话滚动

Status: implemented

## Problem

子任务卡附在主对话末尾，任务越多越拉长消息流；进入子对话后也无法同时观察其他任务及其父子关系。用户需要持续可见的执行概览，同时保持当前阅读位置。

## Decision

Codex 与 Claude 共用主聊天面板左侧的悬浮拓扑卡，以 Provider 已报告的归属组织主 Agent 与各层子 Agent，并支持显式切换对话。拓扑独立滚动且高度受可用空间约束；[正文居中约束](../bug-fix/2026-09-28-subagent-topology-centering.md)替代单侧预留空间，卡片利用正文左侧空白悬浮，空间不足时默认收起并按需展开。

本决策部分替代[子任务摘要](2026-09-22-subagent-task-summaries.md)中把任务卡放入主对话的选择；该记录对阅读焦点、结果来源和缺失信息的约束继续有效。[可理解执行过程](2026-09-22-chat-observable-work.md)及[后台子事件](../bug-fix/2026-09-22-codex-background-child-events.md)仍持有展示语义与事件可达性的决定，不改变 Provider 历史或会话归属。

## Alternatives considered

**在对话末尾继续堆放或折叠任务卡：** 能减少默认展开量，但执行概览仍绑定主对话滚动位置，无法持续观察任务关系。

**只保留顶部 Agent 切换器：** 占用更少空间，但缺少可同时阅读的任务状态与层级；切换器继续作为轻量导航入口。

## Consequences

后台新增任务不增长主对话内容，也不自动改变正在阅读的 Agent。大量任务在拓扑内滚动，左侧空白不足时需要额外一次展开；完整输出仍在所属对话中阅读，拓扑不推断缺失的任务指令或结果摘要。

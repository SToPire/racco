# Agent Note: 首版聊天图片仅供本轮处理

Status: implemented

## Problem

用户需要把截图交给聊天中的 Agent 分析，首版接受历史图片不可回显。为图片长期保存、恢复和回收建立独立资源系统，会使交付成本超过当前需求。

## Decision

图片附件在发送前明确说明本轮处理与历史不保存原图的边界，历史数量占位旁再次说明需要原图时重新上传。界面不能让用户把可发送图片误解为持久附件；当前不引入缩略图保存或延长临时资源寿命。

首页与已有会话支持选择、粘贴、拖拽、多图及纯图片输入。浏览器提供本地预览，图片与文字通过当前内容块协议一次提交；Racco 只在本轮执行中保留图片。图片载荷不进入用户消息快照、Racco 状态库或普通诊断日志；带图片的 SDK stderr 只记录诊断发生，不保留原始分片。纯图片消息在历史中保留位置，图片只显示可确认的数量占位。

服务端在分配会话或受理轮次前，按实际内容校验静态 PNG、JPEG、WebP；任意图片无效即拒绝整条输入。图片数量、字节、像素、解码并发和暂存空间均有上限，传输上限覆盖文字、编码后的图片及消息包装；并发容量不足直接拒绝，不另建等待队列。具体格式和上限由[输入协议](../../../../src/shared/user-input.ts)及[校验实现](../../../../src/server/images/input.ts)持有。

新建会话与首轮启动共用一次完整校验得到的输入租约，从分配会话到执行结束持续占用活跃输入预算，避免对同一请求重复解码。首轮真正受理后由执行任务释放租约；创建失败、启动前失败或已受理请求的重复确认由当前请求释放。并发重复创建仍只分配一个原生会话、启动一轮，后续独立轮次各自校验输入；租约仅在本次操作内传递，不形成可复用的图片缓存。

Codex 使用本轮私有临时文件，匹配轮次终态或确认 Provider 进程退出后才删除；只有本轮启动请求的明确拒绝可提前释放未受理批次，内部或传输错误、中断请求失败与客户端断线不构成删除依据。Claude 使用单条结构化图片消息流，收尾后释放本轮引用。临时目录由状态目录真实路径确定范围，启动取得[内核实例锁](../bug-fix/2026-10-02-kernel-state-instance-lock.md)后、启动 Provider 前清理残留；生产进程组由 systemd 管理，保证旧子进程结束后再启动。关停保持状态锁直到图片清理结束；清理失败计入空间上限并重试，不增加持久清理账本。

Racco 不保存附件资源元数据，不恢复历史图片，不自动重发未确认命令；需要原图时重新上传。Provider 自己的原生记录继续由 Provider 管理。新建请求身份覆盖有序图片摘要与模型配置，状态版本和消息协议只保留当前格式，旧版本直接拒绝。

本记录取代[已拒绝的持久附件提案](../../rejected/feature/2026-09-27-chat-image-input.md)的方案选择，保留其中有界输入、执行收尾与不自动重放的义务。[无逐轮记录](../simplification/2026-09-17-session-state-without-turn-ledger.md)、[原生会话导入](2026-09-18-project-session-import.md)、[完整历史读取](../simplification/2026-09-27-full-history-with-websocket-compression.md)及[原生会话删除](2026-09-19-native-session-delete.md)的存储与所有权边界继续有效，原提案对其持久化范围的拟议扩展已撤销，无其他实现记录需要替代或归档。

## Alternatives considered

**持久附件或可重建历史缓存：** 能改善跨设备及刷新后的图片阅读，但需要资源归属、清理和恢复机制；首版放弃该能力，暂不承担这些成本。只有重新提出历史图片查看需求时才评估。

**先独立上传，再以附件 ID 发送：** 能单独重试大文件，但引入未发送附件的生命周期。当前数量和大小有明确上限，一次随消息提交更简单。

## Consequences

图片可以直接作为模型输入，代价是 base64 的传输与瞬时内存开销、Codex 的短期落盘，以及中断或重启后可能需要用户重新上传。清理 Racco 临时数据不等于删除 Provider 历史中的图片。明确不支持图片的模型被阻止发送，能力未知或上游限制导致的拒绝正常报错，不自动改模型或删图。

[原生接入 smoke](../../../../scripts/smoke-images.mjs)覆盖两家输入、图片清理、历史占位和冷启动续聊；[生命周期测试](../../../../src/server/drivers/codex/images.test.ts)区分终态与不确定异常，[启动测试](../../../../src/server/images/startup.test.ts)约束锁和清理顺序。Provider 的图片内容和退出语义仍应随接入变化验证，不能以历史预览不受支持为由放宽本轮输入完整性。

# Agent Note: Racco 矢量标志资产

Status: implemented

## Problem

项目计划发展为多 Agent 工作台，需要能在应用图标、窄工具栏和完整字标中辨认的独立视觉身份。用户选定 Racco 名称及浣熊方向，并要求直接交付可编辑 SVG。

## Decision

采用圆耳、连贯眼罩和清晰鼻尖组成的浣熊头像，搭配原创路径字标。炭灰与暖米白作为基础色，琥珀用于耳部和应用图标底色；同时提供透明背景、深色背景用字标和真正透明留白的单色版本。所有标志使用独立矢量几何，避免字体安装或外部资源影响渲染。

本记录持有图形资产的设计与交付选择，使用方式由[资产说明](../../../../assets/brand/racco/README.md)持有；产品界面接入与应用标识由[Racco 品牌统一](2026-09-18-racco-product-identity.md)持有。相关现有记录没有定义品牌标志，本记录不替代任何 Agent Note。

## Alternatives considered

**完整卡通角色作为主标志：** 有利于插画表现，但身体、工具和表情细节在窄工具栏中难以保留；主标志聚焦头像。

**位图绘制或依赖字体的 SVG：** 容易制作视觉效果，但缩放、编辑和跨环境显示不够直接；图形与字标均保存为几何路径。

## Consequences

标志可独立用于浅色、深色和单色场景，也能继续扩展吉祥物插画。几何轮廓与字标是统一身份，调整主头像时需要同步对应变体；小尺寸使用独立头像，完整横版保留给有足够宽度的场景。

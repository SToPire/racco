# Agent Note: 开发资料的版本控制边界

Status: implemented

## Problem

本机部署信息、重复安装模板和派生预览会增加仓库维护负担，失效文档引用也会让开发者找不到当前约定。

## Decision

仓库保留产品源码、共享配置、依赖锁文件、测试素材和维护当前项目所需的 Agent Notes 工具。构建与测试输出使用已忽略的目录；本机部署地址不写入共享文档。已安装 Agent Notes 的仓库不附带面向新仓库的初始化工具，品牌资产以可编辑 SVG 为准，不另存 PNG 预览。当前说明引用现存文档或代码。

本记录约束开发资料的收录范围，不替代现有功能决策；[标志资产](../feature/2026-09-18-racco-logo-assets.md)继续持有视觉设计，其他 Agent Notes 继续保留各自的理由与取舍。

## Alternatives considered

**保留完整初始化套件和派生预览：** 方便从本仓库初始化其他项目或查看汇总图，但需要维护与当前项目运行无关的模板和重复资产。

## Consequences

开发者通过 SVG 文件查看标志，其他仓库的初始化工具从技能源单独获取。当前项目的记录编写、维护、评审和检查能力仍随仓库提供，文档改动需要同步修复引用。

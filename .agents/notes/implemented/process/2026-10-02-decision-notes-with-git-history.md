# Agent Note: 以长期决策和 Git 历史维护 Notes

Status: implemented

## Problem

每次非琐碎变更都要求记录，容易重复未变的理由；独立 SHA 封存、清单和可信基线增加维护步骤，却未承载需要额外完整性保证的历史记录。

## Decision

Notes 只记录或更新重要且长期有效的取舍，尤其是所有权、持久化、删除边界及支持约束。常规修复与局部重构在原决定仍准确时无需新增记录。保留当前决定的明确所有者，删除已无指导作用的记录并修复引用，由 Git 保存版本与已删除历史。取消独立封存与可信基线流程。

## Alternatives considered

**保留强制增量记录与 SHA 封存：** 可提供独立历史不可变检查，但当前仓库没有这项保证的使用需求，空清单也没有承载历史内容。Git 审查与当前链接检查更符合现有维护规模。

**删除全部 Notes：** 会丢失代码难以表达的替代方案、所有权与删除理由，因此仍维护真正影响后续选择的记录，不按数量裁撤。

## Consequences

阅读历史需要使用 Git；不再额外验证封存字节未改变。重要决定与现有事实仍要同步，常规任务日志留在提交和任务报告中。结构检查增加当前本地链接校验，不能替代语义审查。本决定按维护者本次简化请求实施，不扩大任何编辑、发布或破坏性操作权限。

此条替代 Notes README 和项目技能中的强制非琐碎变更记录及独立封存规则；检索现有流程记录后，没有其他长期架构或数据归属决定被替代。

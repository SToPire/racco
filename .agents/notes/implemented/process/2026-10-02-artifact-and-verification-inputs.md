# Agent Note: 分开产物与验证输入摘要

Status: implemented

## Problem

测试和诊断脚本变化不改变运行代码，却被混合摘要判为生产产物过期；仅校验运行输入又无法发现完整检查期间测试自身被修改。

## Decision

构建元数据的 sourceDigest 只覆盖运行源码（排除测试）、品牌 SVG、依赖清单和构建配置及入口。完整检查另记录 verificationDigest，覆盖 Git 可见且未忽略的全部文件。产物复用与 doctor 比較前者，完整检查稳定性比较后者；提交号仅提供来源追溯，不单独使相同输入失效。

## Alternatives considered

**所有文件共用一个摘要：** 规则少但诊断将测试改动误报为运行代码变化。两个明确输入集合让构建与验证各自覆盖其责任，不建立通用依赖图或缓存系统。

## Consequences

新增构建入口或独立运行资源时需更新产物输入集合。依赖清单按整文件纳入，因此其中脚本字段改动也要求重建。Git 忽略的生成目录不进入两种摘要。临时 Git 仓库的修改、增加、删除回归约束摘要不可退化为常量。

本条细化[产品标志纳入构建摘要](../feature/2026-09-18-racco-product-identity.md)，保留原资产覆盖要求；检索现有构建与验证决定后无完整替代项。

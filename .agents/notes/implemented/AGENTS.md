# AGENTS.md — Implemented Agent Notes

Follow the [root instructions](../../../AGENTS.md) and [note format](../README.md#the-file-format). Describe completed decisions in the present tense, retaining rationale, important alternatives, ownership and durable obligations.

Update decision-relevant facts with the implementation. Routine changes that leave them accurate need no note update. A changed decision gets a new current owner; retain useful partial rationale, and remove fully superseded records after repairing links. Git preserves their earlier versions. Use [agent-notes-maintain](../../skills/agent-notes-maintain/SKILL.md) for scoped consolidation.
